# Superstore Sales Dashboard (2014-2017)

**Tools:** Power BI, DAX, Data Visualization

### 📊 Overview
Analyzed 9,800+ orders worth $2.26M across 4 regions, 4 categories, and 4 years.

### 🎯 KPIs Created with DAX
- **Total Sales:** $2.26M - SUM(Sales)
- **Total Orders:** 4,922 - DISTINCTCOUNT(Order ID)
- **Total Customers:** 793 - DISTINCTCOUNT(Customer ID)
- **Avg Order Value:** $459.48 - DIVIDE(Total Sales, Total Orders)

### 💡 Key Insights
- Technology is the top-selling Category
- West Region generates highest sales
- Sales grew sharply in 2017 vs 2014
